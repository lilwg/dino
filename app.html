Teaching AI to Play the Chrome Dino Game

An exploration of simulation, learning, and evolution

You know this game — it's the Chrome dinosaur that appears when you lose your internet connection. Simple rules: jump over cacti, duck under pterodactyls. But as the speed ramps up, it gets surprisingly hard. Can we teach a computer to play it?

Approach 1: Forward Simulation

The simplest approach: give the AI a copy of the game's physics engine and let it simulate the future. Every frame, it tries three actions — run, jump, and duck — and picks whichever one avoids obstacles with the most safety margin.

Max Speed: 30

It works — at normal speed. Use the Max Speed slider to crank it up and see how the simulation AI adapts.

This is the fundamental limitation of hand-crafted rules: every decision threshold was tuned for a specific speed range. The AI doesn't truly understand the game — it follows a recipe. Can we build something that discovers its own rules and adapts to any speed?

Approach 2: Q-Learning

What if the AI learns from experience, with no knowledge of the game's physics? Q-Learning builds a lookup table: for every situation, it records how good each action turned out. Every death updates the table — "last time I was in this state and chose to run, I died. Maybe I should jump next time."

We reduce the game to 192 distinct situations by tracking five key features: how close the obstacle is, whether it's a pterodactyl, the obstacle's height (high/mid/low), whether we're already jumping, and whether a second obstacle is close behind.

Q-Learning works — the dino learns to jump over cacti within a few deaths. But the table only captures 192 situations, so subtle timing and unusual obstacle combinations can still trip it up. What if we could extract the rules directly?

Approach 3: Decision Tree

Instead of learning from scratch, let's watch the simulation AI from Approach 1 and learn its strategy. A decision tree splits the data with simple yes/no questions: "Is the obstacle closer than 0.28?" → if yes, "Is it a pterodactyl?" → if yes, duck. Otherwise, jump.

The tree is fully interpretable — you can read every decision it makes.

Learned Rules

The tree discovers the same rules a human might write: jump when something is close, duck for pterodactyls. But each rule is a hard boundary — the tree can't express "jump a little earlier at high speed." What if we use numbers instead of yes/no splits?

Approach 4: Logistic Regression

Logistic regression is the simplest possible "learning" model: multiply each of the 12 game features by a weight, add them up, and pick the action with the highest total. That's it — just 39 numbers (12×3 weights + 3 biases).

We train these weights using gradient descent on the same sim AI gameplay data. Each step nudges the weights to better match the expert's decisions.

Logistic regression is a neural network with zero hidden layers. It can only draw straight-line boundaries in feature space. When those lines aren't enough, it makes mistakes — motivating the jump to a deeper model.

Approach 5: Neural Network (Backpropagation)

Logistic regression draws straight-line boundaries, but the game isn't that simple. A neural network with a hidden layer can learn nonlinear patterns — curved decision boundaries that capture subtle timing relationships.

Our MLP has 12 inputs, 16 hidden neurons with ReLU activation, and 3 outputs — 259 parameters total. Unlike logistic regression's 39, these extra parameters let the network compose features: "obstacle is close AND it's a pterodactyl AND I'm not already jumping" becomes a single hidden neuron firing.

We train it with backpropagation — the gradient flows backward through the network, nudging every weight to reduce prediction error. Same sim AI data, same SGD optimizer, but now with the capacity to learn complex strategies.

The hidden layer makes a big difference — the network learns timing patterns that logistic regression can't express. But we're still learning from a teacher (the sim AI). What if we had no teacher at all — just the game and a score? That's where evolution comes in.

Approach 6: Neuroevolution

What if we add a hidden layer to our logistic regression? That gives the network the ability to learn nonlinear patterns — subtle timing relationships that a straight line can't capture. But with no teacher to learn from, we need a different training method.

Neuroevolution creates a population of 50 small neural networks. Each generation, all 50 play the game. The best performers survive, breed, and mutate. No gradient descent, no teacher — just natural selection.
